# NETWORKING Module

This module manages the networking infrastructure component for the Enterprise IT Operations Automation Platform.

## Usage

This module is called from the environment orchestrator (e.g., environments/dev/main.tf).

## Inputs

| Name | Description | Type | Default | Required |
|------|-------------|------|---------|:--------:|
| project_name | Project name identifier | string | "" | no |
| environment | Deployment environment (dev/test/prod) | string | "" | no |

## Outputs

No outputs are currently exported.
